# Movie Seat Booking — Brad Traversy 50 Projects

Interactive movie seat selection interface using HTML, CSS, and JavaScript.  
This project replicates the exercise from Brad Traversy’s *50 Projects in 50 Days* course.

## Features
- Select and deselect seats  
- Display selected seat count and total price  
- Save selected seats and movie choice in localStorage  
- Restore UI state on page reload  

## Technologies Used
- HTML5  
- CSS3  
- Vanilla JavaScript  
- localStorage  

## Project Purpose
Practice DOM manipulation, event handling, and browser storage.

## How to Use
1. Open `index.html` in your browser.  
2. Select seats and choose a movie to see the total update.  
3. Reload the page to verify that selections persist.
